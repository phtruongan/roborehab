How to build a catkin project in qt.
1. Prepare the source file as https://docs.luxai.com/docs/tutorials/python/python_ros_subscribe
2. Put all necessary files under the project name e.g. 'tutorial_qt_subscribe'
3. Go up to catkin_ws, then run 'catkin_make'
4. Make main python file executable bby 'chmod +x '
5. Create a launcher file as Squat Counter QT in Desktop.
6. Create a Desktop file as QTSquatCounting in Destkop.
7. Make those files executable.
